# SeaDex Data Refinement

SeaDex Data Refinement[^1], brought to you by Lumon Industries[^2],
provides information and identifies specific [SeaDex](https://seadex.moe)
entries that are currently lacking in one way or another.
You can use this site as a resource to stay informed and help contribute to SeaDex.

Browse it at: <https://ravencentri.cc/seadex-data-refinement/>.

For bugs with this site, including entries appearing in the wrong category,
please [open an issue](https://github.com/Ravencentric/seadex-data-refinement/issues).
For issues with SeaDex itself, please report them to the
[SeaDex Discord server](https://discord.com/invite/jPeeZewWRn).

[^1]: <https://severance.wiki/macrodata_refinement>
[^2]: <https://severance.wiki/lumon_industries>
